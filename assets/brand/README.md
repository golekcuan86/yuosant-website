# Yuosant Brand Assets — Black Steel × Teal Green

Source: official Yuosant logo provided and approved in the November 2026 project discussion. The SVG geometry was traced from the supplied logo image, with separate colors for light/dark surfaces.

| Asset | Use |
| --- | --- |
| `yuosant-primary-light.svg` | Horizontal company logo on white/light backgrounds |
| `yuosant-primary-dark.svg` | Horizontal logo on dark backgrounds (ivory text and left arm) |
| `yuosant-symbol-light.svg` | Standalone Y on light backgrounds |
| `yuosant-symbol-dark.svg` | Standalone Y on dark backgrounds |
| `yuosant-app-icon.svg` | Favicon/app mark on dark rounded tile |
| `yuosant-wordmark-light.svg` | Text-only brand on light backgrounds |
| `yuosant-wordmark-dark.svg` | Text-only brand on dark backgrounds |

- Black Steel: `#0C2226`
- Teal Green: `#00C99B`
- Ivory White: `#F4F7F6`

Website header and footer use the **dark-surface** horizontal asset. Light surfaces use the **light** asset. Do not recolor the teal right arm or distort aspect ratio. The current legacy `apple-touch-icon` PNG is retained until a raster replacement is independently validated in target browsers.

This branch is for preview and review. Do not merge into `main`, alter DNS, or release to production without explicit approval.
